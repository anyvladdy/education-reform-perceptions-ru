# Этап 2: сбор государственных сообщений и ответов приёмных комиссий

Сборщики для источников из [`docs/sources/source-registry.csv`](../docs/sources/source-registry.csv), строки со статусом `основной`. Основания — [методология](../METHODOLOGY.md) версии 2.0, разделы 3 и 4.7.

| Источник | Способ | Что сохраняется |
| :-- | :-- | :-- |
| edu.gov.ru (Минпросвещения) | HTTP + BeautifulSoup, обход по дням окон (`/press/news/?date=…`) | Новости: заголовок, дата с минутами, текст, теги |
| minobrnauki.gov.ru, с 2024 г. | HTTP + BeautifulSoup, фильтр сайта по датам окна | Новости: заголовок, дата, текст, рубрика и теги |
| Минобрнауки 2018–2023 | Снимки Internet Archive (CDX API), шаблоны адресов в `config.json` | То же. Раздел «СМИ о Министерстве» помечается в `tags` |
| Telegram: каналы министерств и приёмных комиссий, чаты | Telethon (MTProto) от имени отдельного исследовательского аккаунта | Посты, комментарии к постам, сообщения чатов со связями «ответ на» |
| ВКонтакте: сообщества приёмных комиссий | Официальный API VK | Посты, комментарии с ветками, обсуждения |

## Установка

```bash
cd stage2
python3 -m venv .venv            # или: uv venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env             # заполнить по инструкции ниже
.venv/bin/python check_parsers.py   # офлайн-проверка, сеть и ключи не нужны
```

Файлы `.env`, `.venv/`, `.secrets/` (сессия Telegram) и `data/` в Git не попадают (`.gitignore`).

## Ключи

**Соль псевдонимов `HASH_SALT`.** Авторы сообщений хранятся только как `sender_hash` — хэш идентификатора с солью. Сгенерируйте соль один раз и не меняйте её, иначе псевдонимы разных запусков не совпадут:

```bash
python3 -c "import secrets; print(secrets.token_hex(32))"
```

**Telegram (`TG_API_ID`, `TG_API_HASH`):**

1. Зарегистрируйте отдельный аккаунт Telegram для исследования. Для этого понадобится номер телефона.
2. Войдите на https://my.telegram.org, откройте **API development tools** и создайте приложение. Название и описание произвольные, платформа — Desktop.
3. Скопируйте `api_id` и `api_hash` в `.env`.
4. При первом запуске Telethon спросит номер телефона и код из Telegram. Сессия сохранится в `stage2/.secrets/` и повторного входа не потребует.

Чат ДВФУ доступен только по приглашению. Сборщик вступает в него лишь при флаге `--join`, и это фиксируется в журнале. Участники чата увидят исследовательский аккаунт в списке.

**ВКонтакте (`VK_TOKEN`):**

1. Создайте приложение в кабинете VK ID: https://id.vk.com/about/business/go (тип — веб или standalone).
2. В настройках приложения скопируйте **сервисный ключ доступа** в `VK_TOKEN`. Он не связан с вашим личным аккаунтом.
3. Если на пилоте методы комментариев или обсуждений вернут ошибку доступа, понадобится токен пользователя через авторизацию VK ID. Сторонние сайты-генераторы токенов не используйте.

**edu.gov.ru (`RU_CA_BUNDLE`, необязательно).** Сертификат сайта выдан российским удостоверяющим центром. Если указать путь к его корневому сертификату, проверка TLS будет полной. Без него для `edu.gov.ru` (`insecure_tls_hosts` в `config.json`) проверка отключается, а в журнал пишется предупреждение.

## Запуск

```bash
.venv/bin/python collect.py --source sites --mode pilot            # уже проверено, см. ниже
.venv/bin/python collect.py --source telegram --mode pilot --join
.venv/bin/python collect.py --source vk --mode pilot
.venv/bin/python collect.py --source all --mode full               # полный сбор по окнам
.venv/bin/python collect.py --source telegram --only uni_dvfu_chat --join
```

- **`pilot`** — около 20 записей на источник: самые ранние и самые поздние в периоде. Для сайтов — в первом и последнем окне. В Telegram и VK пилот берёт записи всего периода, чтобы проверить глубину истории.
- **`full`** — все записи в окнах сбора. Окна задаются в `config.json`; рабочее значение — 1 июня – 30 сентября каждого года 2018–2026, верхняя граница — 06.10.2026. Окна меняются до просмотра распределений кодов (методология, 4.6).
- **Возобновление.** Прерванный запуск продолжается с контрольной точки `*_checkpoint.json` без дублей. Для нового запуска с другими окнами укажите другой `--output`.

## Результаты (`stage2/data/<mode>/`)

| Файл | Содержание |
| :-- | :-- |
| `official_sites.csv`, `telegram.csv`, `vk.csv` | Одна строка — одна публикация, комментарий или сообщение; колонки ниже |
| `collection_log.csv` | Журнал: `kind` различает техническую ошибку, недоступность, пропуск вне окна, вступление в чат |
| `manifest_<run_id>.json` | Параметры запуска, версия парсера, SHA-256 таблиц |

Колонки соответствуют таблице `messages` методологии (4.3):
- **`source_id`** — строка реестра.
- **`record_id`**: префиксы `p`, `c` и `b` у VK обозначают пост, комментарий и обсуждение; `c` у Telegram — комментарий к посту канала.
- **`row_type`**: `post`, `comment`, `message` или `board_comment`.
- **`thread_id`, `parent_id`** — связи «ответ на».
- **`published_at`** — дата и время по Москве, **`date_precision`** — точность даты.
- **`period_v1`** — период: `pre_covid`, `covid`, `svo_early` или `svo_late`. **`window_id`** — окно сбора.
- **`title`, `text_raw`, `url`, `tags`** — заголовок, исходный текст, ссылка и теги.
- **`sender_kind`**: `organization` (пост канала или ответ от имени сообщества), `admin` (администратор чата, ранг — в `sender_rank`), `admin_anonymous`, `user`.
- **`sender_hash`** — псевдоним автора.
- **`reply_count`** — число ответов.
- **`collected_at`, `run_id`, `parser_version`, `extraction`** — происхождение записи; `extraction` — способ извлечения.

Имена, логины, телефоны и ссылки на профили авторов не сохраняются, реакции не собираются. При этом `text_raw` — исходный текст: в нём могут встречаться имена и контакты. Перед разметкой он обезличивается в отдельной версии (`text_anon`, методология, раздел 8). Обезличивание этими скриптами не выполняется.

## Пилот сайтов 15.10.2026 (`--source sites --mode pilot`)

| Источник | Записей | Даты публикаций | Замечания |
| :-- | --: | :-- | :-- |
| Минпросвещения, edu.gov.ru | 20 | 01.06.2018 – 30.09.2026 | Полные тексты; TLS без проверки (нет `RU_CA_BUNDLE`) |
| Минобрнауки, живой сайт | 20 | 01.06.2024 – 30.09.2026 | Более ранних новостей на текущем сайте нет |
| Минобрнауки, веб-архив | 12 | 03.09.2018 – 05.06.2021 | 8 из 9 записей 2018 г. — раздел «СМИ о Министерстве», это краткие пересказы чужих публикаций. Полнота снимков архива не установлена |

Из архива пропущено 28 снимков: 21 опубликован вне окон сбора, 7 вышли после 01.01.2024 и уже есть на живом сайте. В пилоте берутся первые и последние снимки по дате снимка, а не по дате публикации, поэтому много пропусков ожидаемо. Полный режим проверяет каждый снимок.

## Ограничения

- **Telegram и VK** проверены только офлайн, на имитации ответов API (`check_parsers.py`). Реальный пилот требует ключей из `.env`.
- **Администраторы Telegram.** Список может быть скрыт; тогда ответы комиссии отличимы только по сообщениям от имени канала. Это записывается в журнал.
- **Сотрудники в VK.** Если сотрудник отвечает от личного аккаунта, без ручной проверки он попадает в `user`.
- **Веб-архив.** Шаблоны адресов 2018–2020 годов проверены на пилоте лишь частично. Набор снимков архива неполон, поэтому доля темы по архивным годам не оценивается (методология, 4.6).
- **Сайты Госдумы и Правительства** в сборщики пока не входят.
