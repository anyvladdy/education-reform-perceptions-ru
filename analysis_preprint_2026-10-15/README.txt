Проверка и результаты
1094 сообщения размечены тремя агентами GPT-6 Luna; 773 включены в анализ.
165 сообщений повторно размечены другим агентом той же модели.
Авторы перепроверили анализ и подтвердили сохранение классификаций и решений.
Подтверждение: audit/author_review_confirmation.json. Это проверка результатов,
а не новая независимая человеческая разметка. Показатели согласия относятся
к исходным модельным решениям до согласования и остаются без изменений.
По части кодов согласие низкое; это учтено в интерпретации результатов.
Новые показатели согласия человека и модели, precision, recall и F1 не заявляются.

Что опубликовано
data/corpus_metadata.json — метаданные без содержания сообщений и исходных URL.
annotations/ — первичные категориальные метки, включая отдельный модельный пилот.
audit/second_*.jsonl — контрольная модельная разметка.
audit/model_adjudications.json — журнал содержательных поправок ИИ.
tables/ — распределения, знаменатели, модельное согласие и чувствительность.
figures/ — семь рисунков в PNG и SVG.
scripts/ — код подготовки, расчётов и сборки отчёта.

Тексты, точные цитаты, свободные пояснения к отдельным меткам, таблица исходных
ID/URL и локальные библиотеки остаются в локальном рабочем архиве. Публичные ID
обозначают записи анализа; они не являются исходными идентификаторами площадок.
В public metadata mode проверка категорий и покрытия выполняется, но проверка
цитат по текстам недоступна. Решения об exact/near duplicates перенесены
из локального анализа; их влияние на итоговые частоты пересчитывается.
Это воспроизведение сохранённых вычислений, а не повторное смысловое кодирование.

Запуск из корня репозитория (Python 3.12)
  python -m venv .venv
  python -m pip install -r analysis_preprint_2026-10-15/requirements.txt
  python analysis_preprint_2026-10-15/scripts/analyze.py
  python analysis_preprint_2026-10-15/scripts/author_report.py
  python analysis_preprint_2026-10-15/scripts/build_report.py

Перед установкой активируйте созданное окружение обычным способом для вашей ОС
или вызывайте его интерпретатор напрямую. Среда Jupyter устанавливается отдельно.
Код не обращается к моделям или сайтам при пересчёте анализа.
Версии библиотек: requirements.txt и audit/runtime_provenance.json.
Перенос на другую версию Python не проверялся.

Редактирование текста
Основной файл — ../DATA_ANALYSIS.md. author_report.py переносит его содержание
в report/report_content.json и синхронизирует report/data_analysis.md; при
отсутствии основного файла использует переносимую копию. build_report.py
формирует HTML и TXT. После правки текста выполните оба скрипта в этом порядке.
При изменении данных требуется содержательный пересмотр текста: числа
в рукописи не подменяются автоматически. Теоретические ссылки относятся
к спискам литературы в ../LITERATURE_REVIEW.md и ../METHODOLOGY.md.

Подготовка данных
scripts/prepare.py и scripts/prepare_audit.py описывают подготовку из локального
исходного архива; для воспроизведения публичных результатов они не требуются.
После изменения правил нужны новая разметка и независимый контроль.

audit/runtime_provenance.json и preparation_notes.json сохраняют обстоятельства
первоначального запуска, до подтверждения авторской перепроверки.
audit/publication_revision_checks.json — проверка сохранности результатов при редактуре.
audit/public_reproduction_check.json — проверка воспроизведения публичного набора.
audit/release_manifest.json — состав файлов и контрольные суммы.
audit/future_human_coding_blank.csv — незаполненный шаблон независимой разметки;
он не описывает и не отменяет состоявшуюся авторскую перепроверку.

Перерисовать только график семейного контекста:
  python analysis_preprint_2026-10-15/scripts/analyze.py --family-figure-only
Режим читает сохранённую vi3_family_profiles.csv и не меняет метки.
