# Реестр источников для досбора

**Дата проверки:** 14.10.2026. **Статус:** кандидаты для пилота (`pilot/state-sources`, `pilot/admissions-sources`). Решения «подходит / не подходит» здесь ещё не приняты.

Таблица: [`source-registry.csv`](source-registry.csv). Её колонки соответствуют таблице `sources` из [методологии](../../METHODOLOGY.md), раздел 4.3. Колонка `status` — основной кандидат или резерв.

## Как отбирались организации

Отбор выполнен по [методологии](../../METHODOLOGY.md) версии 2.0 и решению команды от 14.10.2026: 5 вузов и 5 колледжей, по одному в Москве, Санкт-Петербурге, Екатеринбурге, Новосибирске и во Владивостоке или Хабаровске.

1. **Только государственные организации.** Профили внутри типа различаются:
   - вузы — педагогический, IT и инженерный, классический федеральный, технический, дальневосточный федеральный;
   - колледжи — связь и IT, туризм и сервис, технологии и предпринимательство, химические технологии, медицина.
2. **Принадлежность аккаунта подтверждается ссылкой с официального сайта организации.** Ссылки извлекались из HTML страниц «Абитуриентам» или главных страниц. Адрес страницы-доказательства указан в `evidence_url`.
3. **Ответы в чатах и группах не читались.** Выбор не зависит от их содержания: открывались только публичные карточки Telegram (название, описание, число участников).
4. **Если организация не проходила по пункту 2, бралась другая того же города.** Исключённые кандидаты перечислены ниже.

## Ограничения и задачи пилота

- **Подтверждённые чаты вопросов и ответов есть только у ДВФУ и ИТМО.** В остальных случаях это каналы или сообщества VK. Вопросы там могут задаваться в комментариях, обсуждениях или личных сообщениях, а личные сообщения недоступны. Пилот должен установить, где именно публично отвечает комиссия.
- **Без входа ВКонтакте не показывает содержимое сообществ.** Для пилота нужен доступ через API VK с токеном пользователя. Токен хранится только локально и в Git не добавляется.
- **Аккаунты комиссии в чатах.** В чатах абитуриентов отвечают и студенты, поэтому по методологии нужно отдельно подтвердить, какие аккаунты принадлежат комиссии.
- **Колледж связи № 54.** Ссылки на соцсети найдены на сайте ks54.ru («Все о КС54»), а не на главной странице ks54.mskobr.ru. Описание Telegram-канала колледжа указывает оба сайта. Подтверждение слабее, чем у остальных.
- **Глубина истории чатов** не проверялась. По методологии недоступность ранних кампаний записывается как ограничение охвата.
- **duma.gov.ru** 14.10.2026 не ответил на запрос из среды проверки. edu.gov.ru использует сертификат российского удостоверяющего центра.
- **Числа участников** — на 14.10.2026, только для описания.
- **Профиль.** В основном наборе нет педагогического колледжа и медицинского вуза; педагогический колледж есть в резерве.
