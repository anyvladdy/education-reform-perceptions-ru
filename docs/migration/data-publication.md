# Публикация CSV и Excel

Пользователь явно поручил опубликовать CSV/Excel из ROTMISTROV_PROJECT и объединить все подготовленные PR в main.
Это решение заменяет прежнее ограничение на хранение этих корпусов в Git и прежние сообщения «корпуса остаются локально» в документах переноса и описаниях PR.

Все 45 файлов CSV/Excel сохранены по исходным относительным путям, включая рабочие выборки, полный Telegram-снимок, производные таблицы и результаты демонстрационного запуска. Дубликаты сохранены для совместимости существующих скриптов.
Перечень, размеры, число строк CSV и SHA-256 находятся в published-data.json. Это исторические снимки, а не новые результаты сбора.

Локальные исходники не изменялись. Для точного сохранения байтов CSV отключено преобразование окончаний строк через .gitattributes. Защитные правила .gitignore сохранены; явно разрешённые снимки добавлены адресно и уже отслеживаются Git.

Исторические Telegram CSV могут содержать реакции. Публикация снимков не разрешает их дальнейший сбор или анализ; действующий сборщик не извлекает реакции. Прежняя периодизация и ограничения источников остаются предварительными.

Проверены читаемость CSV, целостность XLSX, контрольные суммы, размеры файлов. Новый сетевой сбор не запускался. Окружения, HTML, контрольные точки и архивы не публикуются.
