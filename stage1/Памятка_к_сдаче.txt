ПЕРВЫЙ ЭТАП: СБОР ДАННЫХ

Для преподавателя нужны два основных файла в одной папке:
1. Этап_1_три_парсера.ipynb — план, три парсера, словарь переменных и ограничения.
2. База_трёх_источников.xlsx — единый Excel с листами Telegram, Пикабу, Табитуриент.

В ноутбуке FULL_RUN = False: Restart & Run All повторно читает до 20 родительских публикаций каждого источника. Связанные комментарии и ответы увеличивают число строк. Демонстрация сохраняется отдельно. Рабочая выборка в основном Excel при этом не меняется.

FULL_RUN = True повторяет сбор по всем адресам готовой выборки.
EXPAND_ARCHIVE = True вместе с FULL_RUN включает расширение через обычные страницы сайтов. Полный обход может занимать часы; MAX_TAG_PAGES явно ограничивает число страниц Пикабу. Предпочтительный вариант длительного сбора — scripts/collect.py, сохраняющий промежуточное состояние.

Примеры запуска из папки scripts:
python collect.py --source telegram --mode archive --output data/new_archive
python collect.py --source pikabu --mode sample --output data/new_sample
python collect.py --source tabiturient --mode sample --output data/new_sample

При изменении дат, словаря или способа отбора задайте новую папку --output: старые страницы состояния относятся к прежним настройкам. Для повторения точно того же набора сообщений используйте адреса основного Excel. Живые счётчики и первоначальные комментарии при новом запуске могут измениться.

Что находится в архиве проекта:
- notebook и Excel;
- три CSV с полными текстами;
- protocol: просмотренные страницы/ID, причины исключения, окна Telegram и границы охвата;
- scripts: версии парсеров с возобновлением, общий запуск и список зависимостей;
- Проверка_запуска.json: результат выполнения всех ячеек в новом ядре.

Границы интерпретации:
- Это тематическая выборка, согласованная командой, а не полный архив и не выборка всех российских семей.
- Публикации и комментарии обрезаны по 06.10.2026 включительно; счётчики прочитаны 07.10.2026.
- Выбранные Telegram-витрины доступны с 2020/2022 года. В выборке Табитуриента материалы начинаются в 2020 году. Не наблюдаемые ранние периоды не заполнены искусственно.
- Для Табитуриента важно различать обычных участников и явные метки приёмных комиссий. В исходной выборке только 7 из 205 ответов имеют такую метку; они относятся к двум организациям. Этого недостаточно для общих выводов о вузах.
- На Пикабу собраны только первоначально загруженные комментарии; в Табитуриенте вложенные комментарии не подгружались; комментарии Telegram не собирались.
- Совпадение слов и focus_candidate не являются подтверждением охлаждения. Нужны ручной отбор и кодирование, в том числе контрпримеров.
- Для более узкого просмотра Пикабу используйте research_screen = True. Это предварительный фильтр: manual_review показывает, какие ветки проверены вручную, а какие ещё нет. Исходные нерелевантные кандидаты сохранены для прозрачности отбора.

Проверочные содержательные примеры:

2021, Минобрнауки: сообщение о проекте сохранения минимальных баллов ЕГЭ на прежнем уровне — https://t.me/minobrnaukiofficial/1669

Последний пример нельзя кодировать как перенаправление в СПО: перечислены программы ВО. Числа и советы в ответе отражают содержание публикации, а не проверенную консультацию.

Согласно документу преподавателя, notebook и единый Excel следует приложить к указанной там форме не позднее пяти дней до встречи. Отправка формы и запись в ведомость за команду не выполнялись.
